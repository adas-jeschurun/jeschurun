4 Материалы
Материалы существуют самостоятельно. В режиме «Выпуск» можно отметить, какие из них входят в текущий выпуск. Открытие опубликованного материала для редактирования создаёт изменения только в staging.
4 Загрузки PDF и EPUB
Добавляйте только те файлы, которые уже готовы. Если файла нет — на сайте просто не появится кнопка скачивания.
5 Файлы R2
Файлы в R2 jes-v2-files (ключи content/…). Сохранение материала пишет в D1 + R2. Удаление — только отсюда с подтверждением.
Нажмите «Обновить список».

Теги и перелинковка

Статистика сайта
Только агрегированная статистика контента. Здесь нет пользователей, IP-адресов, cookies, fingerprint, User-Agent или истории конкретного посетителя.

🗄️D1 + R2 (jes-v2)проверяю…

Сохранение материала пишет в D1 jes-v2-content и бинарники в R2 jes-v2-files. GitHub content не используется. Черновики = status draft; сайт показывает published (draft — через preview-ссылку).

jes-v2-contentd1
Нужны bindings CONTENT_DB / FILES и секрет ADMIN_PREVIEW_TOKEN на jes-v2-admin.
Где хранятся тексты?

Черновик редактора — в браузере. «Сохранить материал» пишет переводы и meta в D1, картинки/PDF/EPUB — в R2. Дружеский GitHub content не трогаем.

Резервную JSON-копию всё равно стоит иногда скачивать.
