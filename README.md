# Jeschurun — автоматическая публикация

С этого этапа HTML сайта вручную не редактируется.

## Структура
- `config/site.json` — настройки, включая `current_issue`.
- `content/issues/<еврейский год>/<slug>/issue.json` — исходник выпуска.
- `content/articles/` — каталог статей.
- `content/biographies/` — биографии.
- `assets/` — общий дизайн.
- `scripts/build.py` — пересобирает весь сайт.
- `.github/workflows/pages.yml` — автоматически запускает сборку и публикацию.

## Архив
5786 начинается с Ки Теце и продолжается дальше. Более ранние главы 5786 задним числом не добавляем.
В 5787 они выйдут в новом цикле и новом формате.

## Текущий выпуск
Явно задаётся в `config/site.json`, например:
`"current_issue": "5786/ki-tetze"`

## Новый выпуск
`python scripts/new_issue.py 5786 <slug>`

Когда готов:
1. заполнить `issue.json`;
2. положить PDF/EPUB в `downloads/`;
3. поставить `"status": "published"`;
4. при необходимости `python scripts/set_current.py 5786/<slug>`;
5. Commit.

GitHub сам пересоберёт главную, архив, страницы выпуска и ссылки.

## Исправление
Меняется исходный `issue.json` или PDF/EPUB. После Commit сайт пересобирается, URL остаётся прежним.

## Печать
Инструкция про поля 5 мм и 100% / Actual size появляется только на странице конкретного выпуска и только если у этого языка есть PDF.

## Подпись внизу сайта
Публичная подпись локализуется по языку: `עדת ישורון` / `Адас Йешурун` / `Adas Jeschurun`.

## Publishing v2

- Главная страница содержит только карточки статей текущего выпуска.
- Полный текст каждой статьи имеет отдельный постоянный URL:
  `/LANG/articles/<article-slug>/`
- Страница выпуска содержит только сведения о выпуске, его PDF/EPUB и карточки входящих статей.
- PDF/EPUB появляются только если соответствующий файл существует и прописан в `issue.json`.
- Переключение языка на странице статьи ведёт на ту же статью на другом языке; языки без перевода скрываются.
